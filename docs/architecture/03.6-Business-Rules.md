# Business Rules
**Project:** Event Management System (Laravel)
**Module:** Digital Document Management System (DDMS)

---

# 1. Pendahuluan

Dokumen ini mendefinisikan aturan bisnis yang digunakan oleh DDMS.

Business Rules menjadi acuan implementasi Service Layer, Validation, dan Workflow.

---

# 2. Document Rules

| Rule ID | Aturan |
|----------|--------|
| BR-001 | Semua dokumen memiliki metadata. |
| BR-002 | Semua dokumen disimpan di Repository. |
| BR-003 | Dokumen tidak boleh dihapus apabila telah diarsipkan. |

---

# 3. Approval Rules

| Rule ID | Aturan |
|----------|--------|
| BR-101 | Hanya Director yang dapat melakukan approval. |
| BR-102 | Approval menggunakan PIN Approval. |
| BR-103 | Dokumen yang ditolak wajib memiliki alasan penolakan. |
| BR-104 | Approval hanya dapat dilakukan satu kali untuk setiap versi dokumen. |

---

# 4. Numbering Rules

| Rule ID | Aturan |
|----------|--------|
| BR-201 | Nomor surat hanya dibuat setelah approval. |
| BR-202 | Nomor surat harus unik. |
| BR-203 | Nomor surat mengikuti format perusahaan. |

---

# 5. QR Verification Rules

| Rule ID | Aturan |
|----------|--------|
| BR-301 | QR dibuat setelah approval. |
| BR-302 | QR mengarah ke halaman verifikasi publik. |
| BR-303 | QR menggunakan hash unik. |

---

# 6. Repository Rules

| Rule ID | Aturan |
|----------|--------|
| BR-401 | Repository menyimpan seluruh dokumen final. |
| BR-402 | Repository mendukung pencarian dan filter. |
| BR-403 | Repository menjadi sumber dokumen resmi perusahaan. |

---

# 7. Security Rules

| Rule ID | Aturan |
|----------|--------|
| BR-501 | Approval PIN disimpan dalam bentuk hash. |
| BR-502 | Audit Trail tidak dapat diubah. |
| BR-503 | Setiap approval dicatat lengkap. |

---

# 8. Integration Rules

| Rule ID | Aturan |
|----------|--------|
| BR-601 | Workflow Proposal tetap berada pada modul Proposal. |
| BR-602 | Workflow Payment tetap berada pada modul Payment. |
| BR-603 | DDMS hanya mengelola lifecycle dokumen. |
| BR-604 | Repository tidak mengubah status bisnis modul lain. |
