# 1. Pendahuluan

## 1.1 Tujuan

Dokumen ini menjelaskan definisi setiap entitas, atribut, relasi, dan aturan pengisian data pada modul Digital Document Management System (DDMS).

Data Dictionary menjadi acuan implementasi:

- Laravel Migration
- Eloquent Model
- Form Request Validation
- Service Layer
- Repository Pattern
- API Design

## 2.3 documents

Repository utama seluruh dokumen.

### Tujuan

Menyimpan metadata dokumen.

### Atribut

| Nama | Tipe | Nullable | Keterangan |
|-------|------|----------|------------|
| id | bigint | Tidak | Primary Key |
| event_id | bigint | Ya | Relasi Event |
| template_id | bigint | Ya | Template yang digunakan |
| title | varchar | Tidak | Judul dokumen |
| document_type | varchar | Tidak | Jenis dokumen |
| source | enum | Tidak | Generated / Uploaded |
| file_name | varchar | Tidak | Nama file |
| file_path | varchar | Tidak | Lokasi penyimpanan |
| file_size | bigint | Ya | Ukuran file |
| mime_type | varchar | Ya | Jenis file |
| archive_status | enum | Tidak | Active / Archived |
| created_by | bigint | Tidak | Pembuat dokumen |
| created_at | timestamp | Tidak | Waktu dibuat |
| updated_at | timestamp | Tidak | Waktu diperbarui |

# 6. Validation Rules

- document_number harus unik.
- verification_hash harus unik.
- approver_id harus memiliki role Director.
- sender_id dan receiver_id harus mengacu ke users.
- file_path wajib terisi.
- title wajib terisi.

---

# 7. Naming Convention

- Nama tabel menggunakan bentuk jamak (plural) sesuai konvensi Laravel yang sudah Anda gunakan.
- Nama foreign key menggunakan format `<entity>_id`.
- Timestamp mengikuti standar Laravel (`created_at`, `updated_at`).
- Enum menggunakan huruf kecil (lowercase) dengan nilai yang konsisten.
