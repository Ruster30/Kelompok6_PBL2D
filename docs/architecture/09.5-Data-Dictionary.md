# 7. Validation Rules

- document_number harus unik.
- verification_hash harus unik.
- approver_id harus memiliki role Director.
- title wajib diisi.
- file_path wajib diisi.
- current_version minimal bernilai 1.
- status wajib mengikuti enum.
- event_id harus mengacu ke tabel events.

---

# 8. Naming Convention

Seluruh tabel menggunakan bentuk jamak (plural).

Foreign Key menggunakan format:

```text
entity_id
```

Contoh:

```text
document_id
user_id
event_id
template_id
```

Timestamp mengikuti standar Laravel:

```text
created_at
updated_at
```

Enum menggunakan huruf kecil (lowercase) dengan format snake_case.
