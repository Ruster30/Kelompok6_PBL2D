Preview Fix Sidebar Scroll

Scroll sidebar ke bawah, klik salah satu menu, lihat posisi scroll-nya tetap (tidak balik ke atas).

Masalah

Kode JS saat ini menyimpan & mengembalikan scroll pada sidebar.scrollTop (elemen #sidebar / <aside>), tapi elemen yang sebenarnya discroll adalah .sidebar-nav (<nav>). Karena aside-nya tidak memiliki overflow-y: auto, nilai sidebar.scrollTop selalu 0.

Perbaikan

// SALAH: scroll disimpan/dikembalikan ke #sidebar (aside)
var sidebar = document.getElementById('sidebar');
sidebar.scrollTop = parseInt(saved, 10);
sidebar.addEventListener('scroll', function() { ... });
// BENAR: scroll disimpan/dikembalikan ke .sidebar-nav (nav)
var sidebarNav = document.querySelector('#sidebar .sidebar-nav');
sidebarNav.scrollTop = parseInt(saved, 10);
sidebarNav.addEventListener('scroll', function() { ... });
❌ Sebelum

Scroll di sidebar hilang saat klik menu karena sidebar.scrollTop selalu 0 — elemen aside tidak discroll.

✅ Sesudah

Ganti target ke #sidebar .sidebar-nav yang punya overflow-y: auto. Scroll tetap di posisi setelah navigasi halaman.

Coba sendiri: Scroll sidebar di sini ke bawah, lalu klik "Dashboard" — perhatikan bahwa posisi scroll akan tetap karena menggunakan sessionStorage.
