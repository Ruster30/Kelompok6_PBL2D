Preview Fix Mobile Sidebar Scroll

Pada mode HP (resize < 768px), scroll sidebar ke bawah, klik menu di bagian bawah — posisi scroll akan tetap, tidak balik ke atas.

Masalah

Ketika sidebar offcanvas di mobile, scroll position sudah disimpan via sessionStorage saat scroll dan beforeunload. Tapi ketika pengguna klik nav link, closeSidebar() dipanggil dulu sebelum navigasi halaman, dan kadang scroll position belum sempat tersimpan.

Perbaikan

// LAMA: scroll tersimpan pasif (hanya via scroll & beforeunload event)
sidebarNav.addEventListener('scroll', fn);
window.addEventListener('beforeunload', fn);
// BARU: scroll TERSIMPAN AKTIF saat klik nav link, SEBELUM sidebar ditutup
navLinks.forEach(function(link) {
  link.addEventListener('click', function() {
    if (window.innerWidth < 768) {
      sessionStorage.setItem('adminSidebarScrollPosition', sidebarNav.scrollTop);
      closeSidebar();
    }
  });
});
Coba di mode mobile: Resize browser < 768px, buka sidebar (klik ☰), scroll ke bawah, klik menu paling bawah — lihat scroll position tetap setelah reload.
